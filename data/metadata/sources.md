# Data sources

## Used (real data)

| File in `data/raw/` | Origin |
|---|---|
| `LSDS-8_Multiplex_serum.cardiovascular.EvePanel_SUBMITTED.csv` | NASA OSDR, study **OSD-575** (SpaceX Inspiration4), Immunoassay, original submitted file |
| `LSDS-8_Multiplex_serum_cardiovascular_EvePanel_TRANSFORMED.csv` | Same panel, ALSDA transformed (wide) version, kept for cross-checking |
| `OSD-575_metadata_OSD-575-ISA.zip` | ISA-Tab study metadata (sample names, sex, timepoints, assay protocols) |

- Study page: https://osdr.nasa.gov/bio/repo/data/studies/OSD-575
- Download pattern: `https://osdr.nasa.gov/geode-py/ws/studies/OSD-575/download?source=datamanager&file=<file name>`
- File list API: `https://osdr.nasa.gov/osdr/data/osd/files/575`
- Downloaded 2026-11-14. Raw files are never modified.

Key metadata facts (from the ISA files):
- 4 crew: C001 (male), C002 (female), C003 (female), C004 (male).
- Panel: Eve Technologies "Human Cardiovascular Disease Panel 3 9-Plex Discovery Assay (HDCVD9)".
- "Measurements were normalized by average of pre-flight values from all crew."

- NASA, How do dangerous blood clots form in space?: https://science.nasa.gov/science-research/science-enabling-technology/how-do-dangerous-blood-clots-form-in-space/
- Inspiration4 paper (Apple Watch heart rate / HRV findings used only to set the *direction* of simulated effects):
  https://www.nature.com/articles/s41586-024-07648-x

## Simulated (not NASA data)

Heart rate and HRV readings are generated by `ai-service/app/simulator/vitals.py`
(fixed seed) and always carry `source = SIMULATED`.
