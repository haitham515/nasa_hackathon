# 30-second demo script

Setup: everything running, dashboard open, press **Reset**. Speed ×1, "Simulated vitals" on.

| Time | Action | What the audience sees |
|---|---|---|
| 0-4 s | Press **▶ Start replay** | Badges `REPLAY ×1`, `NASA OSD-575 biomarkers`, `SIMULATED heart rate / HRV`; four crew cards |
| 4-9 s | (watch) | L-44: three cards turn ATTENTION / REVIEW, alerts labeled *possible data-quality issue*: the AI catches a crew-wide lab batch effect |
| 9-14 s | (watch) | In flight: the orange SIMULATED heart-rate strip rises; vitals alerts with in-flight exercise guidance |
| 14-20 s | (watch) | R+1: **C002 → Review required** from real NASA biomarkers (7 markers below personal baseline); simulated post-landing heart rate up for C001/C002 |
| 20-26 s | Click the C001 **R+82** alert | Score, top biomarkers (α2-macroglobulin, L-selectin, SAP), NASA-sourced "what to do" card, disclaimer |
| 26-30 s | Open **Data & limits** → **NASA results (CSV)** | Honest evaluation and the real/simulated split |

Tip: at speed ×2 the replay itself takes about 12 s and leaves more time for the clicks.
